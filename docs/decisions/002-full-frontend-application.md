# ADR-002 — Mashala generates a complete frontend application

**Status:** Accepted

## Context
An earlier idea treated the conversational UI as an embeddable widget beside an existing frontend.

## Decision
Mashala's primary product is a complete frontend application centered on conversational interaction and deterministic generated forms.

## Consequences
Mashala must address:
- application shell/navigation;
- responsive/mobile behavior;
- styling/theming;
- accessibility;
- session behavior;
- full browser/runtime integration.

The evaluation still requires a fair conventional frontend baseline.
