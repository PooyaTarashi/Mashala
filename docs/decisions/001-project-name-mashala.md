# ADR-001 — Project name is Mashala

**Status:** Accepted

## Context
The working name “Clerk” described the human-service metaphor but was generic. “Mashala” is the author's grandfather's name and connects personally to the motivation that users should not have to understand modern interface conventions to obtain a service.

## Decision
Use **Mashala** as the project name/codename.

Expected naming may include:
- `create-mashala-app`
- `mashala dev`
- `mashala build`
- `mashala.config.ts`
- `@mashala/core`

## Consequences
- Stronger project identity and defense/demo story.
- The name is inspiration only; it does not make elderly users the research population.
